# 工伴·桌面精灵功能清单

## 1. 跟踪 AI Agent 工具 

- 接入 Codex、Claude Code、WorkBuddy 等 AI 工作工具。
- 支持自动发现和配置 Codex、Claude Code 的接入。
- 监控任务运行中、完成和失败状态。
- 识别等待用户输入、决策、确认或授权的状态。
- 在桌面端展示当前任务、任务来源和任务状态。
- 根据工作事件触发机器人的表情、动画、灯光或声音反馈。

## 2. 消息通知

- 通过飞书 CLI 检查当前用户身份，读取今日日程与分配给我的未完成任务。
- 展示飞书任务所属清单、截止时间和原始跳转链接。
- 日历或任务部分缺权时保留已成功的数据，并给出最小权限提示。
- Agent 主动分析用户有哪些待办事项，并进行提醒。
- 支持用户手动输入、查看和处理待办事项。
- 展示 Loop 任务的运行状态、进度、完成和异常情况。
- 通过平台 MCP、CLI 等方式接入监控告警。
- 支持对监控告警进行等级和优先级分类。
- 使用 AI 对告警进行分析、摘要、合并和提醒。
- 支持监控平台的自动化集成与配置。
- 根据电脑使用情况识别用户是否正在工作、专注、空闲或离开。
- 根据用户当前状态选择立即提醒、延后提醒或不打扰。
- 支持喝水提醒和久坐站立提醒。
- 工作日下班前提醒通勤安全，21 点提醒早点下班，23 点后按冷却间隔加强提醒。

## 3. 番茄钟

- 支持开始、暂停、继续和结束番茄钟。
- 支持设置专注时间和休息时间。
- 番茄钟到点后，根据当前任务状态选择立即提醒或延后。
- 任务运行中可以延后提醒。
- 任务结束后只补发一次提醒。
- 支持使用手势确认、暂停、延后或忽略提醒。
- 通过桌面界面和机器人动作提醒用户休息。

## 4. 宠物成长与情绪价值

- 根据用户与宠物的真实互动产生成长变化。
- 解锁新的表情、动画、机器人动作或互动方式。
- 在任务完成、失败和等待介入时提供不同的情绪反馈。
- 在本人在场时随机提供暖心表情，并按摄像头左/中/右位置朝向用户加油。
- 记住用户对提醒频率、庆祝强度和互动方式的偏好。
- 展示宠物成长和内容解锁的来源。
- 不使用勤奋度、工作时长、任务数量或绩效评分作为成长依据。
- 不因任务失败惩罚用户或让宠物成长倒退。
